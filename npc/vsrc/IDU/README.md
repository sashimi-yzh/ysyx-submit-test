# IDU lwq 设计规范
## 1. 整体设计逻辑
IDU lwq 模块整体采用**组合逻辑**实现，并与上下游模块进行**握手交互**，保障指令解析与传输的可靠性。

## 2. 指令分类
指令按功能划分为以下类别：
- 无操作指令
- 计算指令
- 跳转指令
- 访存指令
- 特权指令
- 特殊指令
- 预留扩展指令

## 3. 指令输出接口与编码规则
指令输出接口为 `instruction_out[7:0]`，分为高位类型标识段和低位具体指令段：

| 字段范围 | 功能                | 编码值 | 对应指令类型       |
|----------|---------------------|--------|--------------------|
| [7:5]    | 指令类型标识（高位） | 000    | 无操作指令         |
|          |                     | 001    | 计算指令           |
|          |                     | 010    | 跳转指令           |
|          |                     | 011    | 访存指令           |
|          |                     | 100    | 特权指令           |
|          |                     | 101    | 特殊指令           |
|          |                     | 110-111| 预留（待扩展）     |
| [4:0]    | 指令具体编码（低位） | -      | 各类指令的细分定义 |

## 4. 低位[4:0] 指令细分定义
### 4.1 无操作指令（高位 [7:5] = 000）
- 编码：`00000`（全0）
- 说明：包含 `nop` 指令及所有未实现的指令，统一编码为全0。
